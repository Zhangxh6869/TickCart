# TickCart 启动手册

两条路径，按场景选：

| 场景 | 用哪条 | 特点 |
|---|---|---|
| 日常开发（要改代码） | 中间件容器 + 后端 Maven + 前端 Vite | 热更新，改完即生效 |
| 完整演示（不改代码） | `docker compose up -d` | 一条命令起全套，环境隔离 |

---

## 一、日常开发

### 0. 前置检查

```powershell
docker ps                    # 中间件是否已在跑
curl http://localhost:8080/api/health   # 8080 是否已被占用
```

### 1. 中间件（MySQL 3307 / Redis 6379 / RabbitMQ 15672）

```powershell
cd D:\develop\coding\TickCart
docker compose -f docker/docker-compose.dev.yml up -d
```

容器不常驻，隔天开机后需要重新执行。

### 2. 后端（8080）

**PowerShell**（推荐，端口用命令行参数给，绕开宿主注入的 `SERVER__PORT`）

```powershell
cd D:\develop\coding\TickCart\backend
$env:MYSQL_PORT = "3307"
mvn spring-boot:run "-Dspring-boot.run.arguments=--server.port=8080"
```

**Git Bash**

```bash
cd backend
env -u SERVER__PORT -u SERVER__HOST MYSQL_PORT=3307 SERVER_PORT=8080 mvn spring-boot:run
```

启动时会自动跑 Flyway 迁移（当前 V1→V22），首次约 20 秒。
验证：http://localhost:8080/api/health 返回 200，Swagger 在 `/swagger-ui/index.html`。

### 3. 前端（两个终端）

```powershell
cd D:\develop\coding\TickCart\frontend
pnpm dev:mall      # 终端 A → http://localhost:5173（demo / 123456）
pnpm dev:admin     # 终端 B → http://localhost:5174（admin / admin123）
```

两个 app 的 `vite.config.ts` 都已把 `/api` 和 `/img` 反代到 8080，不需要配跨域。

### 4. 停止

后端 / 前端各自 `Ctrl + C`；中间件：

```powershell
docker compose -f docker/docker-compose.dev.yml down      # 保留数据
docker compose -f docker/docker-compose.dev.yml down -v   # 清空数据
```

## 二、完整演示（Docker）

首次需要构建镜像（拉基础镜像 + 依赖，视网络 10~30 分钟）；之后每次启动只要几秒。

```powershell
cd D:\develop\coding\TickCart
docker compose up -d
docker compose ps        # 5 个服务全 healthy 后可访问
```

| 入口 | 地址 | 账号 |
|---|---|---|
| 商城 | http://localhost | demo / 123456 |
| 后台 | http://localhost:8081 | admin / admin123 |
| 接口文档 | http://localhost:8080/swagger-ui/index.html | — |
| RabbitMQ 管理台 | http://localhost:15672 | guest / guest |

停止：`docker compose down`（保留数据）/ `docker compose down -v`（清空数据）。

**两条路径互斥**：都映射 15672 和 8080，切换前先停掉另一条。

## 三、故障速查

| 现象 | 原因 | 处理 |
|---|---|---|
| `Port 61310 already in use` | 宿主环境注入了 `SERVER__PORT`，覆盖了 `server.port` | 用 `--server.port=8080` 命令行参数（优先级最高） |
| Flyway `Access denied` | 没设 `MYSQL_PORT=3307`，连到宿主机自己的 MySQL 了 | 设环境变量后重启 |
| `Port 8080 in use` | 旧的后端实例还活着 | 先 `curl /api/health` 探活，确认是旧实例再停，别盲目重启 |
| `docker compose up` 报端口冲突 | dev compose 的 rabbitmq 占着 15672 | 两条路径二选一 |
| 镜像拉取超时 | 直连 docker.io 不通 | `.env` 里设 `REGISTRY=docker.m.daocloud.io/library/` |
| 前端改了代码页面没变 | 跑的是旧实例 | 重启对应 `pnpm dev:*` |
| `pnpm` 报 `ERR_PNPM_IGNORED_BUILDS` | 依赖构建脚本被拦 | 白名单已配在 `frontend/pnpm-workspace.yaml` 的 `allowBuilds` |
| 后端启动报 `No default constructor found` | 新增了单测专用构造器但没给 Spring 用的那个加 `@Autowired` | 给 Spring 使用的构造器补 `@Autowired` |

## 四、跑测试

```powershell
cd D:\develop\coding\TickCart\backend
mvn test                                  # 单元测试（跑前先停后端，避免文件锁）
mvn test "-Dtest=*IT"                     # 集成测试（需要中间件在跑）

cd ..\frontend
pnpm test                                 # 前端 vitest
bash ..\scripts\verify.sh                 # 本地等价 CI 全量校验
```
